# Asset provenance and reproduction

Uita airliner is original geometry authored for this project, released CC0. It is a generic research visualization and does not claim manufacturer dimensional or performance accuracy.

- Editable source: `source/uita-airliner.blend` (Blender 5.2.1 LTS).
- Reproducible source: `source/create_assets.py`.
- Runtime: `../public/assets/uita-airliner.glb`, binary glTF 2.0.
- Regenerate: `/Applications/Blender.app/Contents/MacOS/Blender --background --python frontend/assets/source/create_assets.py` from the repository root. On other platforms substitute the Blender executable.
- Coordinates: Blender Z-up, nose along negative Y; exported glTF Y-up. Renderer heading aligns nose with backend true heading.
- Asset is cloned through Three.js/R3F; source geometry and materials are shared.
- Low-poly fuselage, swept wings, stabilizers, engines, cockpit and windows. No external textures.

Airport surface, shoreline, buildings and topography are procedural Three.js display geometry. The terminal, concourses, jet bridges and control tower are loaded from the original Blender-exported GLB described below. Backend airport pack owns runway endpoint coordinates. Terrain is schematic, not a surveyed mesh. Aircraft scale and altitude are exaggerated for legibility.

DM Sans Variable and IBM Plex Mono fonts are bundled through @fontsource packages under their respective SIL Open Font Licenses. Runtime icons are Lucide (ISC).

Airport asset: `source/uita-terminal.blend` → `../public/assets/uita-terminal.glb`, generated by the same script. Original CC0 terminal, concourses, jet bridges, rooftop services and control tower. This display asset is schematic; backend-driven runway meshes remain separate and authoritative. Both GLBs are loaded in the scene.
